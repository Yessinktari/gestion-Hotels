# 🏨 Système de réservation d’hôtel

## 📌 Description du projet
Ce projet est une application web de **gestion de réservation d’un hôtel spécifique**.  
Il permet aux **clients** de consulter les chambres disponibles et d’effectuer des réservations en ligne, tandis que les **administrateurs** peuvent gérer les chambres, les utilisateurs et les réservations via un espace dédié.

L’objectif est de digitaliser et simplifier le processus de réservation et de gestion hôtelière à travers une plateforme centralisée, sécurisée et facile à utiliser.

---

## 👥 Types d’utilisateurs

### 👤 Client
- Consulter les chambres disponibles
- Voir les détails d’une chambre (prix, type, description)
- Effectuer une réservation
- Consulter ses réservations

### 🛠️ Administrateur
- Ajouter, modifier et supprimer des chambres
- Gérer les utilisateurs
- Consulter et gérer les réservations
- Superviser l’activité globale de l’hôtel

---

## ⚙️ Fonctionnalités principales
- Authentification et autorisation (Client / Admin)
- Gestion des chambres
- Système de réservation
- Gestion des utilisateurs
- Interface claire et intuitive
- Sécurité des données

---

## 🧰 Technologies utilisées
- Frontend : HTML-CSS-Bootstrap
- Backend :  PHP
- Base de données : MySQL
